# Dr Nazia Gillani

**R&D Electronics & Embedded Systems Engineer | Product Development | Prototyping & Validation | Sensor Systems & Signal Processing | Design Verification & Testing**

I develop electronic and embedded systems from requirements and architecture through circuit design, firmware, system integration, prototype bring-up, verification and product handover. My experience spans commercial electronics, robotics, healthcare technology and multi-sensor products.

I enjoy hands-on engineering and client-facing development: turning user and system needs into practical designs, solving hardware–software integration problems, and communicating technical trade-offs clearly across multidisciplinary teams.

## Engineering capabilities

- **Electronics:** analogue, digital and mixed-signal design; sensor interfaces; ADC/DAC signal chains; power and reset architectures; FPGA/MCU-based boards; multilayer PCB design and design for manufacture
- **Embedded development:** C/C++, Python, MATLAB, Verilog/VHDL; STM32, ESP32, Arm, FPGA and Raspberry Pi; real-time acquisition, control, telemetry and test automation
- **Sensors and signal processing:** wearable IMUs, thermal sensing and radar; filtering, feature extraction, sensor fusion, calibration and data analysis
- **Product development:** requirements capture, system architecture, component selection, schematic capture, PCB constraints, prototyping, bring-up, fault-finding, verification, validation, documentation and manufacturing handover
- **Collaboration:** client design reviews, clinician and user co-design, technical mentoring, cross-functional teamwork and clear communication with technical and non-technical stakeholders

## Selected engineering work

### Commercial FPGA electronics platform

Developed 28+ page schematics and implementation constraints for complex 6- and 8-layer FPGA boards. Worked with high-speed interfaces including PCIe, Ethernet, USB, SATA and LVDS; supported client engineering reviews, component libraries, design documentation and manufacturing handover.

### Wireless wearable motion-sensing system

Co-developed four battery-powered 9-axis IMU nodes with embedded acquisition, Wi-Fi telemetry and Python-based data capture. Implemented real-time filtering and sensor-fusion workflows for gait applications and trained nine engineers to use and extend the platform.

### Thermal occupancy-sensing prototypes

Built and integrated microcontroller, Raspberry Pi and thermal-sensor prototypes, including Python control, data logging, automated tests and hardware–software debugging.

### MovementGuard

Lead Systems Engineer for [MovementGuard](https://www.movementguard.com/), developing a privacy-preserving movement-sensing product across system architecture, sensing hardware, embedded acquisition, analytics, prototype testing and stakeholder-led requirements.

### Applied signal-processing prototypes

Developed signal-processing and machine-learning pipelines for movement sensing, including tremor quantification with R² > 0.97 and fall detection with 98% accuracy. Radar is one part of this wider experience alongside wearable, inertial and thermal sensing.
